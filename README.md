Hello and thank you for visiting this repository! You will find code for the Arduino Uno’s pulse sensing and pacing process, as well as the code with and without the serial plotter added. There are also data sets from the serial monitor available that were not tested using AI models, to which you are free to utilize them. 

I ask that you credit my work if any data sets or code is utilized in any way, however, please feel free to expand upon this work.
